## KEY LEGAL ARGUMENTS MAP

This shows where each document addresses (or fails to address) the core legal issues.

### Issue 1: Was the arrest lawful under Texas law?

| Document | Position | Key Statutory Argument |
|----------|----------|----------------------|
| **Complaint** | Arrest unlawful — § 502.407 Subtitle A has remedial framework incompatible with arrest | § 502.407 allows 20-day cure, $20 max, dismissal upon compliance; no incarceration |
| **MTD (Dkt 29)** | Arrest lawful — § 543.004(c) only mandates citation for 3 offenses, all others allow arrest discretion | Cites *Atwater*; argues § 543.004(c) is exhaustive list |
| **Opposition (Dkt 33)** | Arrest unlawful — § 543.004(c) is NOT exhaustive; § 502.407 specific remedial scheme controls over general arrest authority | *lex specialis derogat legi generali*; Subtitle A = administrative, not criminal |
| **R&R (Dkt 42)** | ❌ Adopts MTD position wholesale | Mirrors MTD's § 543.004(c) argument exactly; does NOT address § 502.407 remedial scheme |
| **Objection** | R&R committed reversible error — misread § 543.004(c) as exhaustive | 9 distinct errors identified |

## COMPARISON: R&R vs. MTD — WORDING OVERLAPS

The R&R reproduces MTD arguments verbatim in several places. Key examples:

### Statutory Interpretation
- **MTD (Dkt 29, p. 3):** "Thompson overlooks that, under Texas law, speeding, use of a wireless communication device, or a violation of the open container law 'are the only offenses for which issuance of a written notice to appear is mandatory.' Tex. Transp. Code § 543.004(c)"
- **R&R (Dkt 42, p. 4):** "Thompson overlooks that, under Texas law, speeding, use of a wireless communication device, or a violation of the open container law 'are the only offenses for which issuance of a written notice to appear is mandatory.' Tex. Transp. Code § 543.004(c) (emphasis added)."

*Note: The R&R adds "emphasis added" — but the underlying argument is identical.*

### Atwater Citation
- **MTD:** Extensive *Atwater* analysis throughout
- **R&R:** Same *Atwater* cases cited; *Virginia v. Moore* not cited

### Qualified Immunity
- **MTD:** "no clearly established right"
- **R&R:** "even if Thompson's theory is correct (it is not), his argument is so novel that Gonzales would be entitled to qualified immunity"
